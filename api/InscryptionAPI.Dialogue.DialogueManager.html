AddColor(string, string, Color)

Summary

The following is a brief description of what this member does, and what it is meant for:

Adds a new colour code that can be used in dialogue events to colour text.

Colour codes are in the following format:
[c:{code}]{dialogue}[c:]

Bblue
bBbright blue
bGbright gold
blGrbright lime green
bRbright red
brnObrown orange
bSGglow seafoam green (default Act 1 emission colour)
dBdark blue
dlGrdark lime green
dSGdark seafoam green
Ggold
g1bright lime green
g2gold
g3blue
gray40% grey
lGrlime green
Oorange
