OverrideDefaultSlotTexture(CardTemple, List<Texture>, List<Texture>)

Allows you to change the default slot texture for a given 3D scene

public static void OverrideDefaultSlotTexture(CardTemple temple, List<Texture> playerSlots, List<Texture> opponentSlots)

Parameters

temple CardTemple

Indicator for which scene/scrybe this should apply to

playerSlots List<Texture>

Textures for each player slot. Null textures will be replaced with the game's default.

opponentSlots List<Texture>

Textures for each opponent slot. Null textures will be replaced with the game's default.

Remarks

This does not work for Act 2. The base game uses the CardBattleNPC to set default textures. It's possible that a future API update would allow for custom Act 2 NPCs, so this will deliberately not touch Act 2
