Interface IOnCardDealtDamageDirectly

Namespace
InscryptionAPI.Triggers
Assembly
InscryptionAPI.dll

Summary

The following is a brief description of what this type does, and what it is meant for:

Trigger that is triggered when a card deals direct damage. This is a replacement for the vanilla DealDamageDirectly trigger, which unlike the base-game trigger, triggers for all cards on the board and supplies more information.
