ReduceGemifiedBlood(PlayableCard, int?)

Determines whether or not Gemified should reduce the blood cost on a multicost card.

public static bool ReduceGemifiedBlood(PlayableCard card, int? bloodCost = null)

Parameters

card PlayableCard

The gemified PlayableCard we're checking.

bloodCost int?

The PlayableCard's blood cost. Defaults to using the CardInfo's blood cost if null.

Returns

bool

True if Gemified should reduce the blood cost by 1.

Remarks

Used for multicost cards to determine which cost Gemified should affect. Priority from first choice to last: Energy, Bones, Mox, Blood
