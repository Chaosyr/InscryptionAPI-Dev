TribeManager

This class handles the addition of new tribes into the game

TribeManager.TribeInfo

The internal object used to store all relevant info about a Tribe. guid - The mod GUID that added the Tribe. name - The internal name of the Tribe. tribe - The enum value corresponding to this Tribe. icon - The sprite displayed on cards with this Tribe. tribeChoice - Whether or not this Tribe can appear at card tribe choice nodes. cardBack - The texture displayed at card tribe choice nodes. If null, the API will create one using the icon Sprite.
