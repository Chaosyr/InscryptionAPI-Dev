New(string, string, Type, string, string, string, bool, bool, bool)

Creates a new boon and adds it to the list of boons the player can receive.

public static BoonData.Type New(string guid, string name, Type boonHandlerType, string rulebookDescription, string pathToIcon, string pathToCardArt, bool stackable = true, bool appearInLeshyTrials = true, bool appearInRulebook = true)

Parameters

guid string

The guid of the mod adding the boon.

name string

The name of the boom as it should appear in the rulebook.

boonHandlerType Type

A subclass of BoonBehaviour that implements the boon's behaviour.

rulebookDescription string

The description of this boon in the rulebook.

pathToIcon string

Path to the icon that appears in the center of the card art and in the rulebook.

pathToCardArt string

Path to the art that surrounds the boon.

stackable bool

Indicates if the player can have multiple instances of this boon.

appearInLeshyTrials bool

Indicates if the boon should appear in Leshy trials (the boon trials that happen right before battling Leshy in a non-Kaycee's mod run.

appearInRulebook bool

Indicates if the boon should appear in the rulebook.

Returns

BoonData.Type

The unique identifier for this boon.
