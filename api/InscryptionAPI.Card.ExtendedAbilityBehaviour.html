GetOpposingSlots(List<CardSlot>, List<CardSlot>)

Gets the card slots that the card wants to attack

public virtual List<CardSlot> GetOpposingSlots(List<CardSlot> originalSlots, List<CardSlot> otherAddedSlots)

Parameters

Name Description
List<CardSlot>
originalSlots

The set of original card slots that the card would attack (as set by abilities in the base game).
List<CardSlot>
otherAddedSlots

Slots that have been added by other custom abilities.

Returns

Type Description
List<CardSlot>

The list of card slots you want to attack.

Remarks

If your card is replacing the default attack slot (the opposing slot) see 'RemoveDefaultAttackSlot' If you are not replacing the default attack slot, do not include that here. Simple ensure 'RemoveDefaultAttackSlot' returns false. Only return the default attack slot if you want to attack it an additional time.
