Class ExtendedActivatedAbilityBehaviour

Namespace
InscryptionAPI.Card
Assembly
InscryptionAPI.dll

Summary

The following is a brief description of what this type does, and what it is meant for:

A version of DiskCardGame.ActivatedAbilityBehaviour that allows for the creation of activated abilities that cost Blood, Gems, or Health. Also supports dynamic activation costs.
