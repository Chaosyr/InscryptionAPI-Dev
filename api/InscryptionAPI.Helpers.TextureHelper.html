CombineTextures(List<Texture2D>, Texture2D, int, int, int, int)

Combines multiple textures into one, using a tiled approach.

public static Texture2D CombineTextures(List<Texture2D> pieces, Texture2D baseTexture, int xStep = 0, int yStep = 0, int xOffset = 0, int yOffset = 0)

Parameters

pieces List<Texture2D>

The individual textures to combine into the base texture.

baseTexture Texture2D

The background texture for the combined texture.

xStep int

Used to set the position for individual textures.

yStep int

Used to set the position for individual textures.

xOffset int

Used to set the position for individual textures.

yOffset int

Used to set the position for individual textures.

Returns

Texture2D

The modified texture (the same Texture references as ).

Remarks

This helper has a very specific purpose. The pixels in baseTexture will be iteratively replaced with the pixels in the pieces array. The X position for the i-th texture will be xOffset + xStep * i. The Y position for the i-th texture will be yOffset + yStep * (pieces.Count - i - 1).

Note: baseTexture will be modified in-place!
